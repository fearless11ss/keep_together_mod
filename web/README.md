# Website

The Website is a static React and TypeScript SPA built with Vite. It covers
registration, authentication, Devices, recovery, legal records, Profiles,
privacy, data export, account deletion, Reports, and appeals.

It does not host a Node production server or embed inside Minecraft. All data
operations cross Backend Interfaces over HTTPS.

The M0 site is a static Russian-language project-status page. Account and profile
routes are intentionally absent until the Identity and Profiles Modules expose
real Interfaces in M2 and M3.
